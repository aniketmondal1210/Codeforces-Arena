# Maximize `min(x, y)`

## Problem Statement

Given an integer `x`, choose an integer `y` such that:

```
min(x, y) is maximized
```

If multiple valid `y` exist, return any.

---

# Examples

### Example 1

**Input**
```
x = 1
```

**Output**
```
y = 2
```

```
min(1,2) = 1  (maximum possible)
```

---

### Example 2

**Input**
```
x = 3
```

**Output**
```
y = 4
```

```
min(3,4) = 3
```

---

### Example 3

**Input**
```
x = 5
```

**Output**
```
y = 6
```

```
min(5,6) = 5
```
