# Maximize Sum of Medians

## Problem Statement

Given an integer `n`, construct a permutation of size `3n` such that:

- Divide it into `n` contiguous subarrays of size `3`
- Find the median of each subarray
- Maximize the sum of these medians

Return any valid permutation.

---

# Examples

### Example 1

**Input**
```
n = 2
```

**Output**
```
1 5 3 2 6 4
```

---

### Example 2

**Input**
```
n = 1
```

**Output**
```
3 1 2
```
